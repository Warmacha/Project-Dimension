# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Project Dimension** is a Unity 6 game project. Unity version: `6000.3.1f1`. All game code lives under `Assets/` and must be opened and built through the Unity Editor — there is no CLI build command.

## Working with the Project

- Open the project in Unity Hub by pointing it at the `Project Dimension/` directory.
- The entry scene is `Assets/Scenes/SampleScene.unity`.
- C# scripts go in `Assets/` (or subdirectories). Unity auto-compiles them on save; there is no separate compile step.
- The `.csproj` and `.sln` files at the root are auto-generated by Unity for IDE integration (Rider or Visual Studio) — do not edit them manually.

## Running Tests

Tests use the **Unity Test Framework** (`com.unity.test-framework` 1.6.0). Run them inside the Unity Editor via **Window → General → Test Runner**. There is no CLI test runner configured.

## Render Pipeline Configuration

URP settings live in `Assets/Settings/`. There are separate renderer assets for PC and Mobile:
- `PC_RPAsset.asset` / `PC_Renderer.asset`
- `Mobile_RPAsset.asset` / `Mobile_Renderer.asset`

Both have depth texture and opaque texture enabled. When adding post-processing effects, use the Volume system (`Assets/Settings/DefaultVolumeProfile.asset`).

## Ignored Paths

`Library/`, `Temp/`, `Obj/`, `Build/`, `Logs/`, and `UserSettings/` are git-ignored and regenerated by Unity. Never commit them.
